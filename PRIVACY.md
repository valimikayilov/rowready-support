# RowReady CSV privacy policy

Updated 9 September 2026. Applies to RowReady CSV version 1.0.

RowReady CSV is developed by Vali Mikayilov. This policy describes the native Mac application and its separate support channel.

## In the app

RowReady CSV processes files selected by the user on their Mac. It does not transmit file contents to the developer or a server. It has no user account, advertisements, analytics SDK, tracking or network feature. The developer does not collect file contents, usage analytics or device identifiers through the app.

The app uses the macOS sandbox and user-selected file access. It retains the current document in memory during the session. Quitting the app ends that session.

## Exports and change reports

The app writes an output when you export a cleaned copy or a change report. A cleaned copy contains the data you choose to export. A JSON change report contains the source filename, SHA-256 fingerprint, source record numbers, selected transformations and counts. It does not contain cell values.

You decide where to save these files, how long to retain them and whether to share them. Exported files remain until you delete them using your file manager. Storage services you select, such as a synchronized folder or backup service, may upload and retain the files under their own policies. Review the destination folder and report contents before sharing.

## Purchases

The app does not collect payment-card or banking information. When distributed through the Mac App Store, Apple handles purchases under its own terms and [privacy policy](https://www.apple.com/legal/privacy/).

## Public support

Support communications are separate from the app. Requests in the [public GitHub support repository](https://github.com/valimikayilov/rowready-support/issues) can be read by anyone, including the developer. Your GitHub profile, message and attachments may be public. The developer uses these requests to respond and investigate problems.

Use invented example data. Do not include confidential CSV files, credentials, banking details or personal information. Review any change report before sharing: it includes the source filename and fingerprint. Creating a request requires a GitHub account.

GitHub handles account and service information under its [General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). You can edit or delete your own issue content through GitHub, subject to its features and retention policies. For help with a public report, contact the developer through the repository.

## Questions and changes

For questions about RowReady's data handling, [contact Vali Mikayilov through the support repository](https://github.com/valimikayilov/rowready-support/issues/new?template=support.yml). This is a public channel; do not include sensitive data.

Changes to the app's data handling will be reflected in this policy with an updated date.
